# Serial Loopback Pro

### ▶ [เดินดูหน้าตาเครื่องมือในเบราว์เซอร์](https://olay097056.github.io/serial-loopback/)

**เป็นการจำลอง ไม่ใช่การวัดจริง** เบราว์เซอร์เปิดพอร์ต serial ไม่ได้ ตัวเลขจึงถูกเขียนไว้
ล่วงหน้าตามสถานการณ์ที่เลือก — พอร์ตปกติ, เพี้ยนเหนือ 115200, ลืมเสียบ plug, พอร์ตเสีย
สิ่งที่ตรงกับของจริงคือลำดับการทำงานและสถานะ รวมถึงการตรวจหา plug ก่อนเริ่มไล่ทดสอบ

---

เครื่องมือตรวจสอบพอร์ตอนุกรม (serial) ที่ไล่ทดสอบ COM port ครบทั้ง 11 baud rate
โดยเสียบ loopback plug ไว้ แล้วบอกว่าพอร์ตนั้นรับส่งข้อมูลที่ความเร็วไหนได้จริงบ้าง —
ทดสอบต่อเนื่อง พร้อมตารางผล ผ่าน/เตือน/ไม่ผ่าน แบบเรียลไทม์

มีสองเวอร์ชันของเครื่องมือเดียวกัน สำหรับสองโลกที่ต่างกัน

## ทำอะไรได้บ้าง

- **ค้นหา COM port ผ่าน WMI** ทำให้พอร์ตขึ้นมาพร้อมชื่ออุปกรณ์จริง ไม่ใช่แค่ `COM3` เปล่าๆ
- **ตรวจหา loopback plug ก่อนเป็นอย่างแรก** — ส่ง `A5 5A F0 0F` ที่ 9600
  และต้องได้ echo กลับมาถูกอย่างน้อย 3 จาก 4 ไบต์ ถ้าไม่มีขั้นตอนนี้
  การลืมเสียบ jumper จะดูเหมือนพอร์ตเสียทุกประการ และผลทดสอบทั้งชุดจะเป็นขยะ
  เมื่อไม่เจอ plug เครื่องมือจะขึ้น **NO LOOP** แล้วรอ แทนที่จะปั่นตารางผล
  ที่ไม่ผ่านทั้งหมดออกมาให้ดูน่าเชื่อถือ
- **ไล่ทดสอบ 11 baud rate** ตั้งแต่ 1200 ถึง 921600 ให้ผลแยกกันเป็น PASS / WARN / FAIL
- **ตารางสถานะและเกจแบบเรียลไทม์** ที่วาดเองทั้งคู่ พร้อม log แบบเลื่อนดูได้
- **Export CSV** ผลทดสอบ ตั้งชื่อไฟล์ตามพอร์ตและเวลา
- **คืนพอร์ตให้ระบบอย่างถูกต้องเมื่อกดหยุด** — worker thread ถูก join จนจบก่อน
  ปุ่มจะกลับมากดได้ และ log บอกตรงๆ ว่า
  `-- Port released -- safe to open Device Manager --`

ข้อสุดท้ายฟังดูเป็นเรื่องเล็ก แต่ไม่เล็ก เครื่องมือตรวจสอบที่ยังจับพอร์ตค้างไว้หลังกด Stop
จะทำให้เครื่องมือ*ตัวถัดไป*ที่คุณหยิบมาใช้เปิดพอร์ตไม่ได้ แล้วคุณจะเสียเวลาไปดีบัก
ตัวดีบักเกอร์แทนที่จะดีบักปัญหาจริง

## วิธีรัน

**Python:**

```bash
pip install pyserial customtkinter matplotlib
python serial_loopback_pro.py
```

**C# — build ด้วยคอมไพเลอร์ที่มีอยู่แล้วในทุกเครื่อง Windows:**

```bash
C:\Windows\Microsoft.NET\Framework\v3.5\csc.exe /target:winexe /platform:x86 /out:SerialLoopbackPro.exe /r:System.Management.dll SerialLoopbackPro.cs
```

ไม่ต้องมี SDK ไม่ต้องมี Visual Studio ไม่ต้องมี NuGet — `csc.exe` ติดมากับ Windows อยู่แล้ว

## อุปกรณ์ที่ต้องมี

ต้องมี loopback plug คือหัว DB9 ที่ช็อตขา 2 (RX) เข้ากับขา 3 (TX)
ใช้สายยาวสองเซนติเมตรก็พอ ที่เหลือเครื่องมือจัดการให้หมด
